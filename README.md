# Skill Harness

Skill para criar e adaptar harnesses de engenharia a projetos de diferentes linguagens e frameworks. Inclui um ponto de partida genérico para Next.js.

## Instalação no Codex

No Codex, use `$skill-installer` e solicite a instalação de `skills/create-harness` a partir de `https://github.com/yuri-duque/skill-harness`. Reinicie a sessão para descobrir a skill. Depois invoque `$create-harness` no repositório desejado.

Também é possível clonar este repositório e copiar a pasta `skills/create-harness` para o diretório de skills da ferramenta compatível com Agent Skills. Consulte a documentação da ferramenta para o local e a descoberta de skills.

O modelo Next.js em `skills/create-harness/assets/nextjs` é um ponto de partida para adaptar após investigar o projeto e a versão instalada; seus controles não representam implementação ou validação prévia.
