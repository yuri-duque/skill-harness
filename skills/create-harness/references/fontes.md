# Fontes e limites

Consulta externa em 01/11/2026. As fontes fundamentam princípios e exemplos; recomendações concretas devem ser pesquisadas novamente para a stack e as versões do projeto de destino. A taxonomia de pilares é síntese deste guia.

| Fonte primária | Uso e limite |
| --- | --- |
| [AGENTS.md](https://agents.md/) | Entrada de contexto; confirmar descoberta e precedência na ferramenta real |
| [Agent Skills specification](https://agentskills.io/specification) | Estrutura de skills; recursos opcionais variam por agente |
| [Building effective agents](https://www.anthropic.com/research/building-effective-agents) | Decomposição e orquestração; padrões conceituais, não ferramentas obrigatórias |
| [Effective harnesses for long-running agents](https://www.anthropic.com/research/effective-harnesses-for-long-running-agents) | Continuidade e progresso persistente; exemplo adaptável |
| [Demystifying evals for AI agents](https://www.anthropic.com/research/demystifying-evals-for-ai-agents) | Avaliar trajetória e resultado, não só declaração de sucesso |
| [Next.js para agentes](https://nextjs.org/docs/app/guides/ai-agents) | Exemplo de orientação específica de framework; não padrão de outras stacks |
| [OWASP Prompt Injection](https://genai.owasp.org/llmrisk/llm01-prompt-injection/) | Risco de instruções em conteúdo externo e defesas com limites |
| [ANPD: guia de segurança](https://www.gov.br/anpd/pt-br/centrais-de-conteudo/materiais-educativos-e-publicacoes/guia-orientativo-sobre-seguranca-da-informacao-para-agentes-de-tratamento-de-pequeno-porte) | Orientação com escopo em agentes de pequeno porte; não demonstra conformidade geral |
| [PostgreSQL 18: EXPLAIN](https://www.postgresql.org/docs/18/using-explain.html), [índices](https://www.postgresql.org/docs/18/indexes.html), [RLS](https://www.postgresql.org/docs/18/ddl-rowsecurity.html) | Exemplos de pesquisa nativa do motor; substituir por motor/versão reais |

O acesso ao texto da LGPD no portal do Planalto foi bloqueado durante esta pesquisa; não foi feita validação artigo por artigo nem emitido parecer jurídico. O guia determina consultar fontes oficiais vigentes e responsáveis adequados no projeto de destino. Nenhuma pesquisa de stack arbitrária futura foi realizada: o procedimento exige realizá-la após identificar a stack, em vez de antecipar regras universais.
