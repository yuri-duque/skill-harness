# Orientações para agentes

Leia as instruções locais, o README, os scripts e o lockfile antes de trabalhar. Descubra a versão real do Next.js e consulte a documentação correspondente; quando disponível, procure a documentação instalada do pacote.

Antes de alterar a aplicação, consulte arquitetura, decisões e tarefas atuais. Para interfaces, consulte requisitos de acessibilidade e responsividade; para dados, integrações, autenticação ou cache, consulte segurança e contratos reais. Trate dados externos como não confiáveis e mantenha segredos no servidor.

Execute as verificações existentes adequadas à mudança e informe escopo, resultado e limitações. Atualize documentos responsáveis quando comportamento ou decisões mudarem. Não apresente planos como funcionalidades implementadas.
