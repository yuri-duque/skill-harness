# Ponto de partida para harness Next.js

Este modelo genérico é adaptável: não descreve nenhum projeto instalado. Antes de usá-lo, identifique versão, estrutura, runtime, provedor, dados e comandos reais. Consulte a documentação oficial da versão instalada e as instruções de agente suportadas. Escolha os arquivos úteis, integre-os às fontes existentes e substitua marcadores por evidências. Não alegue controles implementados ou validados antes de comprová-los.

Arquivos: `AGENTS.md` é exemplo de entrada; `docs/` contém modelos de arquitetura, qualidade, segurança, interface e decisões. Adicione módulos de banco, integração e operação quando aplicáveis, usando as referências da skill.
